# Useful scripts

Small, reusable tools for local development and cloud jobs.

| Tool | Purpose |
| --- | --- |
| [`uv-env-tool.sh`](uv-env-tool.sh) | Manage user-owned uv and Python environments |
| [`user-apt-tool.sh`](user-apt-tool.sh) | Install selected packages without system-wide sudo changes |
| [`docker-user-tool.sh`](docker-user-tool.sh) | Manage a user-owned Docker setup |
| [`modal_runner/`](modal_runner/) | Run Python projects on Modal with configurable GPU, dependencies, logs and results |

See the [Modal runner guide](modal_runner/README.md) for the one-command workflow and an example configuration.
